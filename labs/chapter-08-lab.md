# Chapter 8 Lab: Text Analysis and Speech Solutions

**Estimated time:** 12 minutes

## Exercise

Extract entities from text with LLM: define JSON schema for output (person, organization, date fields), craft prompt with schema and examples, validate output against schema, compare to traditional NER API results

## Key takeaway

LLM prompting with JSON schema for custom entity extraction; speech agent flow is STT → LLM → TTS; Azure Translator for high-volume production translation.
