# Chapter 9 Lab: Retrieval and Information Extraction Pipelines

**Estimated time:** 20 minutes

Build RAG ingestion pipeline in Azure AI Search: create index with vector field, configure enrichment skillset with OCR and entity skills, ingest PDF documents, test hybrid search query, connect to agent as knowledge source
