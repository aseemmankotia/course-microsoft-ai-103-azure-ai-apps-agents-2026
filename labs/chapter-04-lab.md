# Chapter 4 Lab: Building Agents with Microsoft Foundry

**Estimated time:** 22 minutes

## Exercise

Build multi-agent system in Foundry: create coordinator agent with tool schema for weather API, create specialist agent with Azure AI Search knowledge base, configure sequential handoff, test multi-turn conversation with memory

## Key takeaway

Tool schemas use JSON Schema format with required array and enum for constraints; summary memory for long conversations; coordinator pattern for multi-step agent workflows.
