## Chapter 6: Image and Video Generation Solutions — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What parameter ensures reproducible image generation with identical prompt? | Seed value. Same seed + same prompt/resolution/parameters = identical output. Exam tip: Seed controls random number generator - different seeds produce different images even with same prompt. |
| 2 | Inpainting vs Outpainting - what's the difference? | Inpainting: replace masked regions WITHIN image bounds (e.g., remove object, change background). Outpainting: extend canvas BEYOND current borders (e.g., expand scene). Exam tip: Inpainting = edit existing, Outpainting = expand canvas. |
| 3 | What is reference image conditioning in video generation? | Feeding example images to define visual style/appearance for generated video. Combines image input + text prompt for multimodal control. Exam tip: Most reliable way to maintain brand consistency across video generations. |
| 4 | What does image-to-image strength parameter control? | How much the output deviates from input image. Low (0.3-0.5) = preserve structure, vary details. High (0.7-0.9) = major changes. Exam tip: Strength 0.3-0.5 for variations of same design, 0.7+ for major transformations. |
| 5 | How does Azure AI's embedded watermarking differ from visible watermarks? | Embedded: imperceptible patterns in pixels, survives cropping/screenshots/compression. Visible: text/logo overlay, easily removed. Exam tip: Embedded watermarking is for regulatory compliance (can't be stripped), visible is for branding. |
| 6 | What are the 4 content safety categories for image generation? | Violence, Sexual, Hate, Self-Harm. Can set sensitivity (low/medium/high) per category. Exam tip: Enable ALL categories for comprehensive protection - question scenarios often involve users trying to bypass filters. |
| 7 | When does content safety prompt analysis occur? | BEFORE generation (pre-generation). Analyzes text prompt and rejects unsafe requests before API call completes. Exam tip: Pre-generation blocking saves quota and prevents unsafe content from ever existing in system. |
| 8 | What is prohibited-symbol detection used for? | Identifies and blocks generation of copyrighted logos, trademarks, brand symbols. Exam tip: Different from content safety filters (violence/sexual/etc) - specifically for IP protection and brand usage rules. |
| 9 | Negative prompts - what do they control? | Elements to AVOID in generation (e.g., 'blurry, low quality, watermark'). Reduces likelihood but doesn't guarantee prevention. Exam tip: Negative prompts are guidance, not security filters - use content safety for hard blocks. |
| 10 | What image generation models are available in Azure AI Foundry catalog? | Stable Diffusion variants, DALL-E (via Azure OpenAI). Foundry provides model deployment/inference, not custom training. Exam tip: Foundry = catalog of pre-trained models you deploy, not custom model training platform. |
| 11 | Common resolution aspect ratios in image generation APIs? | Square (1:1, e.g., 1024×1024), Landscape (16:9, e.g., 1792×1024), Portrait (9:16, e.g., 1024×1792). Exam tip: Model may have max resolution limits (e.g., DALL-E 3: 1024×1024, 1792×1024, 1024×1792 only). |
| 12 | How do style presets differ from prompt-based style control? | Style presets: predefined options (e.g., 'photorealistic', 'anime', 'oil painting') applied as parameter. Prompt-based: describe style in text (e.g., 'in the style of Van Gogh'). Exam tip: Presets = consistent, limited options; prompts = flexible, variable results. |
