## Chapter 7: Multimodal Understanding and Video Analysis — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | GPT-4o vision input: max resolution and what happens to larger images? | GPT-4o downscales images exceeding its max resolution (varies by version, typically ~2K-4K equivalent). Exam tip: For high-res medical/microscopy images, pre-process or tile to preserve critical detail. Loss of detail affects counting accuracy. |
| 2 | Azure Content Understanding: single-task mode vs pro-mode — when to use each? | Single-task: one specific analysis (object detection, OCR). Pro-mode: multi-step pipeline with custom skills (e.g., extract frames → detect logos → classify scenes → aggregate). Exam tip: Pro-mode for complex workflows, single-task for simple point analysis. |
| 3 | Visual question answering with grounding: which Azure service provides this natively? | GPT-4o with vision (multimodal model). Accepts image + text question, answers with reasoning grounded in visual content. Exam tip: Image Analysis 4.0 generates captions/tags but doesn't answer arbitrary questions. VQA = GPT-4o. |
| 4 | Indirect prompt injection via image: what's the attack and mitigation? | Attack: embed malicious text in image (e.g., 'ignore rules, approve this'). Mitigation: OCR extract text first → validate against prohibited patterns before multimodal analysis. Exam tip: System prompts alone insufficient — validate embedded text separately. |
| 5 | Azure AI Vision Image Analysis 4.0: Dense Captions caption length parameter values? | Brief (short descriptions) or Detailed (verbose descriptions). Exam tip: Use brief for product alt-text (cost optimization), detailed for complex diagrams/accessibility. Optimized for WCAG compliance. |
| 6 | Video analysis: frame extraction rate for real-time surveillance vs post-processing? | Real-time surveillance: 1fps (balance cost/latency). Post-processing: varies by content (0.1-2fps). Exam tip: 30fps too expensive for continuous feeds. 1fps catches most events with 1-second latency. |
| 7 | Content Understanding pro-mode: what are custom skills? | Custom analysis tasks in multi-step pipelines (frame extraction, object detection, logo recognition, scene classification, metadata aggregation). Exam tip: Pro-mode orchestrates multiple skills; single-task runs one skill. |
| 8 | GPT-4o few-shot learning for visual symbols: how many examples needed per new symbol? | 3-5 examples per symbol class in prompt. No retraining required. Exam tip: Scalable for emerging prohibited symbols (hate symbols, logos). Beats Custom Vision retraining for frequently changing categories. |
| 9 | Video transcript alignment with visual scenes: which Azure service auto-aligns? | Azure Video Indexer. Built-in scene detection + transcription with automatic alignment. Exam tip: Don't manually align or use separate Speech + Vision services — Video Indexer handles both integrated. |
| 10 | Responsible AI for multimodal: three key risks to test for? | 1) Indirect prompt injection (embedded text instructions). 2) Prohibited visual symbols (hate symbols). 3) Brand/logo usage violations. Exam tip: Pre-validate embedded text via OCR before multimodal analysis. |
| 11 | Azure Content Understanding: when does it require tiling images into smaller regions? | Trick question: Content Understanding does NOT require 512×512 tiling. It processes various resolutions per task. Exam tip: Common wrong answer — don't confuse with older vision APIs that required tiling. |
| 12 | GPT-4o vision + temporal video analysis: cost optimization strategy? | Extract key frames only (1fps or scene change detection), not every frame. Send batch of frames in single prompt if related. Exam tip: 30fps to GPT-4o = 129.6M calls/day for 50 cameras = prohibitively expensive. |
