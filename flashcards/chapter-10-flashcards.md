## Chapter 10: Full Exam Simulation and Test-Taking Strategy — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | AI-103 exam: How many questions and how much time? | 40-60 questions in 100 minutes (some sources say up to 120 min). Includes case studies. Pace: 1.5-2 min per question, allocate 10+ min per case study. Exam tip: Flag difficult questions and maintain pace - you can review flagged questions at the end. |
| 2 | Case study time strategy: 5 related questions, estimated 12 minutes, 45 minutes remaining for 20 total questions. What do you do? | Read scenario, answer 2-3 easy questions (3-4 min), flag hard ones, move on. Return later if time permits. Exam tip: Don't spend full estimated time upfront - capture quick wins and maintain overall pace. |
| 3 | AI model fabricates medication names not in source documents. Regulatory requirement: all outputs must be traceable. Which Responsible AI control? | Grounding with citations. NOT Content Safety filters (those detect harmful content, not fabrication). Exam tip: Grounding = prevents fabrication, Content filters = harmful content, Prompt shields = injection attacks. |
| 4 | Azure OpenAI: When to use Provisioned vs Standard deployment? | Provisioned: Predictable latency SLA, high/consistent volume, guaranteed throughput (measured in PTUs). Standard: Variable workloads, pay-per-token, shared infrastructure. Exam tip: SLA requirement or 'consistent response time' = Provisioned. |
| 5 | Document Intelligence: Invoice model misclassifies shipping invoices as purchase orders. Fix WITHOUT retraining? | Run both Invoice and Purchase Order prebuilt models in parallel, route based on higher confidence score. NOT custom model (requires retraining). Exam tip: 'Without retraining' = use prebuilt models, parallel comparison, or confidence thresholds. |
| 6 | Azure AI Search: Vector search returns gaming laptops for 'laptop with long battery life'. How to improve relevance? | Hybrid search = vector + keyword (BM25). Combines semantic understanding with exact keyword matching. NOT just increasing k (returns more results, doesn't improve ranking). Exam tip: Keyword-specific queries = hybrid, purely semantic queries = vector only. |
| 7 | AKS pod needs Azure OpenAI auth. Security policy: no secrets in code/env variables. Solution? | Workload Identity (managed identity for pods). NOT Key Vault (still requires secret to access vault), NOT Kubernetes secrets (still stored secrets). Exam tip: 'No secrets' + AKS = Workload Identity. Always prefer managed identity over keys. |
| 8 | Exam elimination strategy: narrowed to 2 options, unfamiliar topic, 60 min left, 25 questions remaining. What do you do? | Choose one, flag for review, move on immediately. 25Q in 60min = 2.4min/Q pace. Can't afford 5+ min on one question. 50% odds on guess vs 0% if skipped. Exam tip: Flag = you'll return; skip = might forget. |
| 9 | Responsible AI: Prompt injection attack detected. Which control prevents this? | Prompt shields (Jailbreak detection). NOT Content Safety filters (output content), NOT grounding (fabrication). Exam tip: Injection/jailbreak = prompt shields, harmful output = content filters, fabrication = grounding. |
| 10 | Azure AI Agent Service vs custom OpenAI + Cosmos DB for chatbot with SQL data access and multi-turn conversations? | Agent Service = built-in conversation state + native SQL connector. Custom = must build conversation tracking and DB integration. Exam tip: 'Minimize development time' + conversation + data sources = Agent Service. |
| 11 | AI-103 domain weights: Which domains are 30-35% (focus review) vs 10-15% (skim)? | 30-35%: Generative AI solutions, AI agents. 10-15%: Smaller domains like specific Vision or Language features. Exam tip: Spend study time proportional to domain weight - don't over-study 10% domains. |
| 12 | Common exam traps: Managed identity vs API keys, Provisioned vs Standard, Hybrid vs Vector search. What's the exam's bias? | Exam prefers: Managed identity (not keys), Provisioned (when SLA/consistent latency mentioned), Hybrid search (when keywords matter). Exam tip: If scenario says 'no secrets' or 'secure' = managed identity. If 'SLA' or 'predictable' = Provisioned. |
